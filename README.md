# XMind AI Workspace

**让 AI 接着你的导图工作。读取、修改、保存，下次继续。**

一个可复制到自己账号的 XMind 云工作区，面向 ChatGPT / Codex 使用。围绕原生 `.xmind` 文件工作，提供目录、读取、搜索、节点编辑、多画布操作和版本历史。

![使用流程](docs/overview.svg)

## 解决什么问题？

- **已有导图交给 AI 很麻烦**：无需每次重新截图、整理文字，直接读取文件结构与节点。
- **一次生成后难以继续完善**：可以修改已有节点、移动分支、增加画布，沿用同一份文件。
- **聊天结束后文件散落**：个人云目录保存导图，新对话从仓库继续读取。
- **多次传递容易拿错版本**：文件版本校验拒绝过期修改，Git 历史可找回旧版。

它可作为 XMind 插件在**导图读取、结构编辑与持续管理**场景下的替代方案；仍使用 XMind App 查看和手动编辑。无需额外 XMind AI 服务来执行本工具的本地文件操作；AI 服务、GitHub 和 XMind App 各自的账号与功能要求仍适用。与 XMind 官方无隶属关系。

## 先跑通一次：无需配置云端

1. **Code → Download ZIP**，解压到普通文件夹。
2. 本地安装 Python **3.10+**，无需安装任何 pip 依赖。
3. Windows 双击 **`run.cmd`**；macOS / Linux 执行 **`bash run.sh`**。
4. 选择 **3：跑通示例修改**。原图会保留，另生成 `00_临时/入门示例-修改后.xmind`。
5. 用自己的 XMind App 打开修改后的文件，检查中心主题。

仓库已附通用示例及修改后的对照文件。**当前发布已通过文件读写、工作区自动检查，以及 GitHub 云端修改与自动提交验证；这一版示例的 XMind 客户端打开 / 保存仍需在使用者设备上确认。** 先用示例确认兼容，再处理自己的文件副本。

## 建立自己的云目录

点击仓库 **Use this template → Create a new repository**，将工作区复制到你的账号。存放私人导图时选择 **Private**。这会建立你的独立目录，不会把文件写到作者的仓库。

- [打开云目录](CATALOG.md)
- `00_临时`：随手产生、尚未分类
- `10_进行中`：正在处理
- `20_草稿`：尚未成熟
- `30_长期`：长期维护
- `90_归档`：已结束但保留

把 `.xmind` 上传到合适目录；下载或 Git 同步后可在电脑、平板、手机的 XMind App 打开。**跨设备同步需要你上传 / 下载或使用 Git；不是 XMind 官方云，也不是实时多人同步。**

刷新目录：`python workspace.py list`，然后提交 `CATALOG.md`。AI 云端修改成功后会自动刷新目录。

## 让 AI 开始工作

将下面的话发给能访问你仓库的 ChatGPT / Codex：

> 读取我的 XMind 工作区的 README 和 AI 使用说明。仓库是【你的仓库链接】，目标导图是【文件路径】。先读取当前文件，说明结构；我确认具体修改后，再执行并告诉我保存结果。

完整流程见 **[上手指南](docs/GETTING_STARTED.md)**，AI 的必要调用约定见 **[AI 使用说明](AI_USAGE.md)**。

## 可直接使用的能力

| 想做什么 | 支持情况 |
| --- | --- |
| 查看目录、画布、节点层级，按关键词查找 | 支持 |
| 改名、新增、删除、移动节点 / 分支 | 支持 |
| 增加自由主题、设置位置 | 支持 |
| 增加、改名、删除画布 | 支持；保留至少一个画布 |
| 在本地直接修改文件 | 支持，Python 标准库即可 |
| 提交请求后由 GitHub 自动修改并保存 | 支持，需要启用 Actions 和仓库写入权限 |
| 修改关系线、边界、概要、图片、复杂样式等 | 本版不承诺主动编辑；未涉及的文件载荷会保留 |
| 老式仅包含 `content.xml` 的格式 | 不支持；使用现代含 `content.json` 的 `.xmind` 文件 |

## 更少等待，更方便接续

本地工具直接读取 / 修改文件，**本地路径不必等待云端插件响应或 GitHub Actions 排队**；同一请求可批量完成多个节点操作。云端路径更方便在能写仓库的对话中使用，但仍有 Actions 排队时间。

[性能记录](docs/PERFORMANCE.md)区分本地工具耗时与完整 AI 操作耗时。没有发布未经实测的第三方插件速度倍数。

## 使用时记住两点

- **外部修改前先保存并关闭 XMind 文档；同步后重新打开。** XMind 不会自动刷新已打开文档，保存旧窗口可能覆盖新版本。
- 同一张图避免跨设备同时编辑。Git 历史可以恢复文件，但 `.xmind` 冲突不自动合并。
