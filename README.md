# XMind AI Workspace

**让你常用的 AI 直接接着导图工作，本地与云端各点一次就能同步。**

![使用流程](docs/overview.svg)

## 解决什么问题？

- **不绑定 AI 模型、模式或平台**：能读写仓库，并能执行工具或提交云端请求的 AI 就能接入；不必依赖特定 XMind 插件。
- **不设导图同步数量上限**：用自己的仓库保存和同步 `.xmind`，本系统不设置“10 张导图”等数量门槛，也不要求购买 XMind 云同步订阅。*
- **多画布、批量操作**：读取任意画布，精确增删改移节点、调整自由主题、增删改画布；一次处理多项修改。
- **已有导图持续完善**：文件、目录和版本历史留在自己的工作区，新对话可以继续处理。
- **同步时机由你决定**：获取云端更新、上传本地修改，各点一个按钮，省去手动 Git 命令。

## 怎么用？

1. 点击 **Use this template**，建立自己的云工作区；私人导图选择 **Private**。已有工作区可以继续使用。
2. 将自己的工作区克隆到电脑。[首次准备](docs/SYNC.md#首次准备)
3. [下载 Windows 同步程序 XMindSync.exe](https://github.com/duohaocui-eng/xmind-ai-workspace/releases/latest/download/XMindSync.exe)，打开并选择本地工作区。**无需安装 Python，复用已有 Git 认证。**
4. 把工作区链接和导图路径交给具备仓库操作能力的 AI，说明这次要读取或修改的内容。
5. 根据方向点击同步：

| 我要做什么 | 点击 |
| --- | --- |
| 把 AI / 云端的修改拿到电脑 | **获取云端更新** |
| 把电脑上保存的修改交回仓库 | **上传本地修改** |

**上传前保存导图；获取前先保存并关闭相关 XMind 文档，完成后重新打开。**

发给 AI：

> 工作区是【仓库链接】，导图是【文件路径】。读取 README 和 AI_USAGE，基于最新导图帮我【具体要求】，按我的要求修改并保存。
