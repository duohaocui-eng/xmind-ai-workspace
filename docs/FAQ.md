# 使用问答

**需要 XMind 官方 AI 插件吗？** 本工具的文件读取和编辑不依赖该插件。需要查看和手动编辑时，使用你自己的 XMind App。

**会修改作者的仓库吗？** 不会。使用模板建立自己的仓库后，在自己目录里工作。

**只能在 GitHub 使用吗？** 本地工具不依赖联网。云目录和云端自动执行使用 GitHub；下载 ZIP 也能体验本地流程。

**云端返回成功但本地没变？** 点击同步程序的“获取云端更新”，再重新打开相关 XMind 文档。获取前先保存并关闭旧窗口。

**为什么哈希不匹配？** 文件在请求生成后已改变。重新读取最新文件，并用新请求 ID 和最新哈希提交。

**同名节点怎么处理？** 用精确节点 ID；标题有歧义时不会猜测。

**怎么恢复？** 打开仓库文件历史，下载上一版本，确认后另存为恢复文件。先保留当前版本。不要对二进制冲突做自动文本合并。

**打开失败？** 先使用当前 XMind App 保存一份现代 `.xmind` 文件副本。仅含 `content.xml` 的旧格式不支持。先在副本验证；本次发布未对所有客户端和高级结构做兼容承诺。

**Actions 没启动？** 检查是否启用、文件是否恰好为 `requests/request.json`、是否已提交；手动运行可重试同一个已完成请求而不重复添加节点。

**Actions 无法提交？** 检查仓库工作流写权限及分支保护；推送冲突时重新读取最新文件并生成新请求，不 force push。

**本机需要 Python 吗？** Windows 同步程序不需要。只有使用可选的本地读写脚本时才需要。

**同步是否需要新账号？** 不需要。复用已有 Git 仓库和 SSH / HTTPS 认证。
