# 1.1.0 · AI 不绑定，一键同步

- 新增 Windows 双按钮同步程序：获取云端更新、上传本地修改。
- 复用已有 Git 认证；Windows 打包版不需要安装 Python。
- 正常操作一键完成；冲突时保留双方副本，上传失败保留本地提交。
- 不绑定特定 AI 模型、模式或平台；接入条件是具备需要的仓库读写与执行能力。

- 首页集中展示解决的问题和使用步骤，详细说明移至次级文档。
