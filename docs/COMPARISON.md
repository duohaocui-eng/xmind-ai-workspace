# 这个工作区与插件路线的区别

工作区把原生 `.xmind`、个人目录和版本历史交给自己的仓库管理，再接入具备仓库读写和执行能力的 AI。

| 关注点 | 本工作区 |
| --- | --- |
| AI 选择 | 不绑定特定模型、模式或平台；按当前环境可用的仓库读写和执行能力接入 |
| 同步导图数量 | 系统不设固定张数配额；受实际存储、文件大小和运行额度约束 |
| 画布范围 | 可指定任意画布；支持新增、删除和重命名画布 |
| 编辑方式 | 按节点 ID 精确增删改移，自由主题位置与批量操作 |
| 文件归属 | 自己的本地文件与仓库，可使用 Git 版本历史 |
| 本地往返 | 人控制时机，双按钮获取 / 上传，复用现有 Git 认证 |
| 执行位置 | 本地执行或 GitHub Actions，按实际环境选择 |

## 关于“免费版 10 张”

截至 2026-10-31，XMind 国际官网的 [Windows 同步说明](https://xmind.com/help/save-sync-manage-files-windows)列出 My Works 上传限制：Free 最多 10 张、Pro 最多 50 张。[价格页](https://xmind.com/pricing)也将 Free 的手动创建在线导图列为最多 10 张，并说明 AI 积分相关例外。

这是官方在线工作区 / 云同步的配额，不能写成“所有本地导图最多 10 张”或“每一种插件创建都绝对只能 10 张”。本项目直接使用自己的仓库，不设置这一张数配额，也不依赖 XMind 官方云同步服务。XMind App 的其他付费功能不会因此解锁。

## 关于“只能操作首画布”

用户此前使用插件时遇到过首画布限制，但本次核查到的当前 XMind 插件接口已包含画布列表、新增画布以及指定 sheetId 读写。因此不再把“插件当前只能操作首画布”作为普遍事实宣传。

本项目明确提供任意画布定位、批量节点操作和个人仓库工作流；这不等于声称当前官方插件在所有操作上都更弱。关系线、边界、复杂样式等主动编辑能力仍以本项目 [AI 使用说明](../AI_USAGE.md)声明的范围为准。

相关官方说明：[ChatGPT 插件](https://xmind.com/user-guide/chatgpt-apps)、[MCP 接入](https://xmind.com/user-guide/xmind-mcp)。套餐与接口会更新，请以当时官方内容为准。
