# 使用边界与可选入口

## AI 接入

系统不按模型名称、推理模式或 AI 产品类型限制接入。需要当前环境实际具备工作区访问权限，以及下列一种执行路径：

- 本地读取二进制文件并运行现有工具；
- 读取二进制文件后生成请求并写入仓库，由 GitHub Actions 执行。

只能看仓库网页、不能读取文件或写入请求的环境，不能直接完成自动编辑。详见 [AI 使用接口](../AI_USAGE.md)。

## 文件与客户端

以含 `content.json` 的现代 `.xmind` 文件为真源。支持摘要、搜索、节点增删改移、自由主题位置、多画布增删改和批量请求。

不承诺主动编辑关系线、边界、概要、Notes、链接、marker、图片和复杂样式；未修改的非 content 载荷会保留。客户端兼容性请先用副本验证。

本地同步不会让已经打开的 XMind 文档自动热刷新；先保存关闭，获取更新后重开。

## 数量与资源

本工作区没有固定导图张数上限，但实际容量、Git 单文件大小、Actions 额度、AI 可用能力及 XMind App 功能仍以所用服务为准。它不解锁 XMind 客户端自身的付费功能。

## 可选工具入口

需要脱离云端体验文件读写时，可安装 Python 3.10+ 后运行 `run.cmd` 或 `bash run.sh`。这是可选入口；Windows 同步程序不要求 Python。

## 目录与恢复

五个导图目录按生命周期组织，`CATALOG.md` 提供文件入口。Git 历史保留已提交版本，可通过 Git 客户端找回；同张二进制导图冲突不自动文本合并。

同步程序只上传导图及索引；获取云端更新会同步仓库更新，上传时也会整合无冲突的云端更改。详细操作见 [同步说明](SYNC.md)。
