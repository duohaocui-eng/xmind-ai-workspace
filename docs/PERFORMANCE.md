# 本地性能记录

这是运行工具本身的耗时，不包含 AI 思考、GitHub 请求、Actions 排队、文件同步和 XMind App 打开时间。

环境：本次 Linux 执行环境，Python 3.12.14；通用入门示例，单画布、4 个节点。每项独立启动 Python 进程 20 次，取中位数，包含进程启动开销。

| 操作 | 中位耗时 |
| --- | ---: |
| 摘要读取 | 48.5 ms |
| 修改并验证 | 48.6 ms |

样本很小，不能据此推断大图性能，也没有与指定第三方插件做同任务实测。可以确认的使用差异是：本地路径直接处理文件，不需要等待云端插件或 Actions；云端路径仍有网络和排队开销。
